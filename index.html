About RainWise

RainWise is a rainwater harvesting monitoring website prototype. It demonstrates rainfall tracking, tank storage estimates, water usage charts, manual water records and roof collection calculations. This version uses simulated data and browser local storage. Live sensor integration can be added in a future version.
